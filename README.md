# PLC-HIMACO

## Respaldo de hojas

Use **Exportar respaldo PDF** para descargar todas las hojas guardadas en un PDF que también contiene los datos necesarios para restaurarlas. Para recuperar un respaldo, seleccione **Importar respaldo PDF** y elija un PDF exportado desde PLC-HIMACO. La importación reemplaza todas las hojas guardadas actualmente.
